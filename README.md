# Library Management System

A simple Library Management System developed using Core Java.

## Features
- Add books
- View all books
- Search books by ID
- Issue books
- Return books

## Technologies Used
- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)

## How to Run

Compile the Java files:

```bash
javac book.java librarymanagement.java
```

Run the program:

```bash
java librarymanagement
```

## Future Improvements
- Connect to MySQL using JDBC
